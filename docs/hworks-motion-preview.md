# H-Works 스크롤 연출 미리보기

## 범위

승인된 방향에 따라 **H-Works 한 구간만** 수정한다. 상단 히어로와 반복되던 문 열림·제목 분할·커튼을 제거하고 가역적인 네이티브 스크롤 장면을 유지한다. FateSpoiler/모두ERP는 아직 같은 강도의 연출로 확장하지 않았다. `preview/glass-nav` 전용이며 운영 `prod`에 병합하지 않는다.

기존 JoyHero, globals.css, GlassNav, 프로젝트 사실 데이터, 상세 페이지는 SHA-256 보존 테스트 대상으로 변경하지 않았다.

## 장면

- 실제 `h3` 하나를 거대한 중앙 제목으로 표시 → 부드럽게 축소하여 좌측에 도킹. 제목을 복제하거나 자르거나 숨기지 않는다.
- 붉은 배경은 전체 면의 불투명도로 전환한다. 제목이 도킹한 뒤 분류 문구와 역할 텍스트가 나타난다.
- Architecture / Automation / Operations 타이포그래피 순차 진입 → 축소·좌측 배치.
- 실제 기여 내용·상세/서비스 링크가 읽기 구간에서 표시.
- 읽기 구간 이후에도 제목·역할·기여·링크를 유지한다. 고정 구간이 끝나면 실제 FateSpoiler article이 아래에서 올라오며 H-Works를 밀어 올린다. 다음 프로젝트를 복제한 전환 레이어는 없다.
- 네이티브 스크롤 진행값의 순수 함수로 계산하므로 역방향도 같은 구성으로 복귀.
- 가짜 서비스 화면은 사용하지 않으며 타이포그래피임을 표시.

데스크톱 이동 거리 290svh, 모바일은 160svh의 별도 연출 뒤 일반 흐름 본문. 모바일 진행 거리는 CSS의 실제 margin-top 값을 측정해 주소창 변화 때 svh/innerHeight 오차를 피한다. reduced-motion/no-JS/짧거나 내용이 넘치는 화면에서는 정적 본문으로 전환한다.

## 접근성·검토 반영

- 숨겨진 링크는 inert, 보이는 ‘기여와 링크 보기’로 읽기 장면에 진입.
- 역방향 키보드 진입은 마지막 링크로 이동.
- 버튼 내부 화살표 클릭도 처리.
- 기존 focus-within z-index 승격/blur 우회 제거: 실제 포커스가 가려진 경우에만 위치 보정.
- 정적/연출 상태의 본문 측정 폭을 동일하게 유지하여 ResizeObserver 진동 방지.
- 중첩 RAF 취소, 이벤트/observer 정리 및 아이들 RAF 종료 검증.

## 이번 수정의 검증

- `npm run build`, `npm run typecheck`, `npm test`: 통과, 단위/계약 테스트 56개.
- SHA-256 회귀 테스트: JoyHero, globals.css, GlassNav, 프로젝트 데이터, 상세 경로 보존.
- 실제 effect의 제목 축소·역방향 복원, 고정 해제 이후 본문·링크 유지, RAF 종료·정리 검증.
- 브라우저 테스트 갱신: 단일 제목의 크기·도킹 좌표·겹침, 역할 재배치, 실제 다음 article의 진입·역방향 경계, 키보드 접근, 모바일 reduced-motion 및 no-JS 제목·링크.
- Codex 샌드박스 안에서는 Chrome 시작이 SIGABRT/EPERM으로 막혔으나, 상위 Hermes 환경에서 실제 Chrome 실행으로 검증을 완료했다.
- 전체 브라우저 회귀: 데스크톱/노트북 5종 + 태블릿/모바일/정적/감소 모션 6종, no-JS 2종 통과. 실행시간 제한으로 데스크톱·모바일 배치를 분리했다.
- Fable 5.1 정적 검토의 작은 태블릿 제목/역할 겹침과 짧은 노트북 캡션 잘림을 보완. 추가 800×600·899×700을 포함한 10개 뷰포트의 정/역방향·제목·링크·전환 경계를 실제 브라우저로 검증했다.
- `pnpm lint`는 보존 대상 JoyHero.tsx의 기존 미사용 STACKS(TS6133) 때문에 실패. 이번 범위에서 원본 수정하지 않았다.
- 비교 브랜치만 커밋·푸시·배포하며 운영 반영·병합·전역 도구 설정 변경은 하지 않는다.

브라우저 전체 검증은 오래 걸리므로 뷰포트별 분할 실행 가능:

```sh
PORTFOLIO_URL=http://127.0.0.1:3187 \
PLAYWRIGHT_MODULE=/absolute/path/to/playwright \
PORTFOLIO_VIEWPORTS=desktop,laptop,desktop-1024 \
pnpm test:browser

# 별도 배치: mobile,small-mobile,reduced-motion
# 기본값은 전체 뷰포트. 정적 export 서버는 확장자 없는 상세 경로를 .html로 제공해야 함.
```

방향은 승인된 범위로 고정한다. 배포 후에도 비교 URL에서 실제 브라우저 검증을 수행한다.
